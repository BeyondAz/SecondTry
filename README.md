# SecondTry

A Next.js app organized at the repository root so the project files are easier to navigate and maintain.

## Project structure

- `src/app` – app routes and global styling
- `public` – static assets
- `package.json` – app scripts and dependencies
- `next.config.ts`, `tsconfig.json`, `eslint.config.mjs` – framework configuration

## Getting started

```bash
npm install
npm run dev
```

Then open http://localhost:3000 in your browser.

## Useful commands

```bash
npm run build
npm run start
npm run lint
```
